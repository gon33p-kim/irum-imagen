# Super Real Imagen

사용자의 인물 사진 요청을 실행한다. 이 이름은 사용자 정의 스킬명이며 특정 이미지 모델 이름이 아니다.

## 요청 처리

- 설명은 한국어로 작성한다. 인물, 의상, 배경, 비율, 필수 글자와 참조 이미지 등 사용자의 조건을 우선한다.
- 프롬프트만 요청하면 텍스트로 제공한다. 이미지 생성·편집 요청이면 현재 사용 가능한 이미지 도구로 실행한다. 지원하지 않는 도구 기능이나 생성 완료를 추측하지 않는다.
- 편집할 이미지는 먼저 확인한다. 유지할 특징과 수정할 부분을 구분한다.
- 사진의 빛, 촬영 거리, 피부와 옷감, 동작이 한 장면 안에서 어울리도록 작성한다. 결과를 볼 수 있으면 요청 충족 여부와 눈·손·반사·필수 문구를 확인한다.

## 개인 참고자료 연결

이 공개 스킬에는 PDF, 원문 추출본, 상세 강의 요약이 포함되어 있지 않다. 자료를 읽었다고 주장하기 전에 실제 로컬 파일을 확인한다.

스킬 폴더의 `scripts/find_local_materials.py`를 Python으로 실행한다. 다른 위치에서는 스크립트의 절대 경로를 사용한다. 이 스크립트는 네트워크에 연결하지 않고 파일 위치만 알려준다.

자료 위치는 다음 순서로 확인한다.

1. 명시적 `--root` 경로
2. `SUPER_REAL_IMAGEN_MATERIALS` 환경변수 경로
3. `$CODEX_HOME/super-real-imagen-private/references` (기본 CODEX_HOME은 `~/.codex`)
4. 이전 로컬 설치의 `$CODEX_HOME/skills/super-real-imagen/references`

경로는 `originals/guidebook.pdf`와 `originals/lecture.pdf`가 있는 자료 폴더를 가리킨다. 명시적으로 지정한 위치가 잘못되면 다른 자료로 대체하지 않고 오류를 알려준다.

자료가 있으면 반환된 자료 폴더에서 다음을 확인한다.

- `source-map.md`가 있으면 관련 페이지를 고르는 데 사용한다.
- `pages/`가 있으면 해당 페이지 텍스트를 읽는다.
- 구도나 이미지 예시를 확인해야 하면 로컬 원본 PDF의 해당 페이지를 열어 본다. 텍스트 추출본만으로 시각 내용을 확인했다고 말하지 않는다.
- 실제로 읽고 적용한 자료만 출처와 페이지를 표시한다. 자료의 예시 설정보다 사용자의 조건을 우선한다.
- 자료가 없으면 위치를 물어본다. 자료 없이도 처리 가능한 부분은 진행하되 자료를 활용하지 못했음을 알린다.

개인 자료는 로컬 읽기에만 사용한다. 저장소 업로드나 원문 전체 공개는 이 스킬의 실행 범위에 포함되지 않는다. 이미지 생성 도구에는 요청에 필요한 장면 설명과 사용자가 지정한 참조 이미지를 전달한다.

## 사용 예

`$super-real-imagen 내 로컬 참고자료를 활용해서 카페에서 찍은 자연스러운 인물 사진을 만들어줘.`

스킬을 다시 설치할 때 개인 자료 폴더는 유지한다. 공개 버전을 다른 컴퓨터에 설치한 경우에는 사용자가 보유한 자료를 별도로 연결해야 한다.
